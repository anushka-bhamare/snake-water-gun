# Snake Water Gun Game

A simple command-line Snake Water Gun game developed in Python as a beginner-level programming project.

## About the Project

Snake Water Gun is a command-line game similar to Rock Paper Scissors. The player selects one of three options, and the computer randomly selects another option. The winner is determined according to the game rules.

This project was created to practice fundamental Python programming concepts and implement them in a simple interactive application.

## Game Rules

| Choice | Defeats |
| ------ | ------- |
| Snake  | Water   |
| Water  | Gun     |
| Gun    | Snake   |

* If the player and computer select the same option, the result is a draw.
* Otherwise, the choice that defeats the opponent's choice wins.

## Features

* Play against a computer opponent
* Choose between Snake, Water, and Gun
* Generate random computer choices using Python's `random` module
* Determine the winner using conditional statements
* Display results for wins, losses, and draws
* Interactive command-line gameplay
* Simple and beginner-friendly implementation

## How to Run


### 2. Open the Project

Open the project folder in Visual Studio Code or another Python-compatible IDE.

```bash

```

If the Python file has a different name, replace `snake_water_gun.py` with the appropriate filename.
